== Mission

Ajouter, **en plus** de Maven Central, la publication au **Gradle Plugin
Portal** avec le compte **`cccp-education`** stocké dans les secrets GitHub, et
rendre le choix de la cible **granulaire** (Portal, Central, ou les deux), la
restriction Sonatype courant jusqu'au 2026-12-01.

== Changements

=== Workflow `.github/workflows/test.yml`

* `workflow_dispatch` avec l'entrée `target` (choix) :
  - `plugin-portal` (**défaut**),
  - `maven-central`,
  - `both`.
* Job `publish` : déclenché sur un tag `v*` **ou** en `workflow_dispatch`,
  toujours `needs: [test]`.
* Étape **Gradle Plugin Portal** (`if: target != 'maven-central'`) :
  `./gradlew publishPlugins --no-daemon` dans `academy-plugin`, avec
  `GRADLE_PUBLISH_KEY`/`GRADLE_PUBLISH_SECRET` lus depuis les secrets
  `CCCP_GRADLE_PUBLISH_KEY`/`CCCP_GRADLE_PUBLISH_SECRET` et `CI=true`.
* Étapes **Maven Central** (`if: target == 'maven-central' || target == 'both'`) :
  import GPG, configuration OSSRH, `publishAggregationToCentralPortal`.
* Un tag `v*` publie donc par **défaut sur le Portal** (restriction Sonatype) ;
  `maven-central`/`both` restent disponibles à la demande.

=== Secrets GitHub (repo `cccp-education/academy-gradle`)

Ajoutés (valeurs jamais affichées, lues depuis `~/.gradle/gradle.properties` du
compte `cccp-education`) :

|===
| Secret | Rôle
| `CCCP_GRADLE_PUBLISH_KEY` | clé API du compte `cccp-education`
| `CCCP_GRADLE_PUBLISH_SECRET` | secret associé
|===

* `OSSRH_USERNAME`/`OSSRH_PASSWORD`/`GPG_PRIVATE_KEY`/`GPG_PASSPHRASE` ne sont
  **pas** présents dans les secrets du dépôt : la cible `maven-central`/`both`
  échouera tant qu'ils ne sont pas ajoutés (les publications Central passées
  étaient locales). Cela n'affecte pas la cible `plugin-portal`.
* Les variables d'environnement `GRADLE_PUBLISH_KEY`/`SECRET` de la session
  locale appartiennent à un **autre compte** ; les secrets CI utilisent
  explicitement le compte `cccp-education`.
