- `platform("org.springframework.boot:spring-boot-dependencies:4.1.2")` +
  `spring-boot-starter-webflux` + `kotlinx-coroutines-reactor` +
  `tools.jackson.module:jackson-module-kotlin` + Kotlin 2.4.10.
- `compileKotlin` VERT ; `runApplication` démarre **Netty sur 18080 en 3,6 s** ;
