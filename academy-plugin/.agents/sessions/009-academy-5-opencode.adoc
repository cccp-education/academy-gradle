== REFACTOR + Dogfooding (preuve réelle — leçon S-007)

`publishToMavenLocal` + `buildAllInstallers` sur le consommateur racine, puis
**exécution réelle** de l'installeur Linux dans un HOME isolé :

* `sh -n seed.sh` → VALIDE ; `jq opencode.json` → VALIDE ;
* `docker compose config` → VALIDE ; services = postgres/moodle/moodle-seed/
  ollama/portainer + `workspace` en profile `agent` ;
* **`docker build` du Dockerfile généré → SUCCÈS** ;
* `docker run … echo` → `whoami=learner`, `zsh`, `gradle 9.7.1`, `java 25`,
  `git`… **et `opencode --version` = 1.18.31**.

*Bug trouvé par le dogfooding* (D-ACADEMY-5-11) : le build-time
`RUN curl … opencode.ai/install | bash` s'exécutait après `USER root` →
install dans `/root/.opencode`, invisible au `learner` (`command not found`).
Correctif : `USER learner` **avant** l'install + `ENV HOME=/home/learner`.
Prouvé par rebuild réel (`Successfully added opencode to $PATH in
/home/learner/.bashrc`) puis `opencode --version` en tant que `learner`.
