== Objet

Suite de la session 018. Le reste de la porte d'accessibilité (GBL-011-5) est
l'audit **Moodle** (jusqu'ici déclaré hors périmètre faute de navigateur). Mission :
mesurer l'accessibilité des pages Moodle **réellement servies** par la boîte, sans
navigateur, et prouver la mesure sur l'image réelle.

  opencode terminal audits require a browser/session ».

  montre que `$CFG->wwwroot` est écrit depuis `SITE_URL`, et que l'image fixe
  `SITE_URL=http://localhost` **par défaut**.

== BS-6 — Dogfooding réel + bug compose découvert

Mise en place d'un consommateur `/tmp` (academy 0.0.3 en mavenLocal), génération
de l'installeur Linux, extraction du compose **généré**, `docker compose up -d
moodle` (PostgreSQL 16 + `erseco/alpine-moodle:v5.2.3` réels).

- **Bug réel P0 découvert** : `GET /course/index.php` répond `303 Location:
  http://localhost/login/index.php` — l'image fixe `SITE_URL=http://localhost`
  (port 80), alors que la boîte publie **8080**. Toute navigation Moodle sort du
  port publié dès qu'un redirect interne est émis. Le compose généré ne
  surchargeait pas `SITE_URL`.
- **Correctif** : `composeBody()` déclare `SITE_URL: http://localhost:8080` pour
  le service `moodle` (source unique Linux/Windows), verrouillé par
  `InstallerScriptGeneratorTest` (« moodle publishes its links on the host
  port ») + un scénario BDD `@installer`.
- **Preuve après correctif** : `config.php` contient `$CFG->wwwroot =
  'http://localhost:8080'`, `303 → http://localhost:8080/login/index.php`,
  puis `auditMoodleAccessibility` sur `/login/index.php` + `/course/index.php`
  → **`VERIFIED`, 0 finding** (les deux pages sont la même page de connexion
  après redirect). Stack supprimée (`compose down -v`).
- `capsule` (audiodescription) reste le seul producteur manquant : le constat
  vidéo reste un `WARNING` déclaré. L'audit opencode (TUI) reste une limite
  déclarée.
