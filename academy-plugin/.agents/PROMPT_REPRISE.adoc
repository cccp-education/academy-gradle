== Décisions actées S-014 (ne pas les rediscuter)

* **Matrice d'engine** (D-ACADEMY-12-1) : Linux = Docker Engine natif ;
  Windows = **Docker Desktop** (`install --user --quiet --accept-license
  --backend=wsl-2`, WSL2 **requis et géré par Desktop**) ; macOS = **Colima**
  (MIT). **Portainer partout** (uniformité apprenant, même URL `:9000`).
  **Supersede D-ACADEMY-6-12** (« Portainer remplace Docker Desktop » = erreur
  de catégorie : Portainer est une GUI, pas un moteur).
* **Le runner GitHub Windows est écarté** : les runners ne fournissent que des
  conteneurs **Windows** (Moodle/PostgreSQL/Ollama/Portainer sont Linux).
* **Contrainte reboot assumée** (D-ACADEMY-12-4) : l'activation WSL2 exige admin
  + reboot possible → installateur **idempotent/resumable**. Ne JAMAIS promettre
  « un run sans reboot ».
* **Portabilité** (D-ACADEMY-12-5) : un seul `install.sh` (en-tête par OS, queue
  commune `compose up` + `.env` + seed via `composeBody()`), un `install.bat`.
