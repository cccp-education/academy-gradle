== Rappels des ordres de mission

- BDD/TDD baby-step strict : RED → GREEN → REFACTOR, 1 fichier de test avant le code.
- Gouvernance d'abord pour toute décision pilote (pattern S-057).
- **L'image est préconstruite avec ses outils natifs** : ne jamais construire
  une stack (ni PHP maison, ni SQL direct) — vérifier l'image avant de coder.
- Parité cross-plateforme : source unique partagée > doublon asserté.
- DAG N2 : academy importable par N3, jamais N3 → academy.
- Zéro secret. `publishToMavenLocal` obligatoire après modification de source.
- Code anglais only (OSS cccp-education), docs gouvernance en français.
- **Dogfooding = preuve réelle** (leçon récurrente S-007/S-012/S-013).
- **Ne jamais inventer** un nom d'image, de tâche, de provider, de fonction ou
  de champ CSV : vérifier la source (S-007 `moodle:4.5`, S-013 le CSV de
  `moosh course-list`).
