## Rappel des ordres de mission

- BDD/TDD baby-step strict : RED → GREEN → REFACTOR, 1 fichier de test avant le code.
- Gouvernance d'abord pour toute décision pilote (pattern S-057).
- Parité cross-plateforme : tout service/contenu transverse est asserté Linux ET
  Windows — **préférer une source unique partagée plutôt qu'un doublon asserté**.
- DAG N2 : academy importable par N3, jamais N3 → academy.
- Zéro secret dans le code. `publishToMavenLocal` obligatoire après toute modification de code source.
- Code anglais only (OSS cccp-education), docs gouvernance en français.
- **Dogfooding = preuve réelle** : un test vert ne prouve pas qu'un scaffold
  s'exécute (S-007 l'a démontré — `moodle:4.5` passait les 43 checks et était
  inexistant).
